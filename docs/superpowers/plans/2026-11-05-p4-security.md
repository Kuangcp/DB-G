# P4：密码加密与连接档案导入导出（实施记录）

## 已完成

1. `app/crypt.go`：`Vault` 用 AES-256-GCM（密钥 `secret.key` 0600，缺失时生成 32 字节随机）；密文 `enc:v1:<base64(nonce|cipher)>`；非该前缀视为明文原样返回。
2. `ConnStore`：内存保留明文，`save()` 落盘前加密（密钥不可用则拒绝写密码）；`LoadStore` 解密，**发现明文密码时自动加密回写**；解不开（密钥变更/密文损坏）→ 警告 + 密码置空，要求重填。
3. `app/profilexfer.go`：`ExportProfiles(path, conns, includePassword)`（默认去密码，文件 0600）；`ImportProfiles(path, existing)`（按关键字段去重、id 冲突重映射）。
4. UI：设置窗口「连接档案：导出连接（不含密码）/ 导入连接…」；导入后刷新树与健康检查。
5. 健康检查：`probeConn`（3s 超时，Open+Close）；启动时后台检查 + 侧栏「刷新」触发；侧栏状态点绿/红；headless 同步版本可测。
6. 测试：加密往返/密钥权限/换钥失败、落盘无明文、明文迁移、损坏密文警告、导出无密码/导入去重与 id 重映射/垃圾文件、健康检查（有效/缺失文件）、设置窗口按钮；全量 7 包绿。

## 取舍

- 导入时 `store.Add` 仍会校验 sqlite 路径；不存在的文件会被跳过并记日志（测试已按此约定）。
- 未做「导入时选择是否包含密码」的二次确认 UI（导出默认不含；含密码导出能力已在 app 层具备，UI 暂不暴露）。
- 健康检查每次全量探测（连接多时略慢，3s 超时上限）；未做定期刷新。
