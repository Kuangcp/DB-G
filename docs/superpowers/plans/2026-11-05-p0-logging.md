# P0：可观测性（日志/诊断） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 db-g 的关键行为（启动、连接、执行、控制台、补全加载、落盘失败、panic）落成本地可查的日志，并在设置窗口给出日志入口——为后续所有阶段提供排查手段。

**Architecture:** `app/log.go` 提供无第三方依赖的 JSON Lines 日志（一天一文件、5MB 轮转、`0600`、可注入目录/时钟/写入器、stderr 同步），包级 `app.LogInfo/LogWarn/LogError` 在未初始化时安全降级为 no-op；`ui` 只调用这几个函数。`rootView` 每帧加 `recover` 兜底 panic，记堆栈并在顶栏显示错误。

**Tech Stack:** Go 标准库（`encoding/json`、`os`、`sync`、`runtime/debug`）、mygo（`mygo.Shell.ShowItemInFolder`）。

**Spec:** `docs/superpowers/specs/2026-11-05-db-g-roadmap-v2-design.md`（P0 一节）

## Global Constraints

- 不新增依赖；`CGO_ENABLED=0`；全量 `go test -p 1 ./...`。
- 日志文件权限 `0600`，目录 `0700`；**不得写密码**（DSN/连接档案脱敏）。
- 未初始化日志时所有调用必须安全（no-op），不得 panic、不得产生文件。
- 日志写入不得阻塞 UI 超过可忽略量（本地同步写小行；不引入后台队列）。
- 文案中文；提交信息 `taskN: …`。每任务收尾绿：`CGO_ENABLED=0 go test -p 1 ./...`、`go vet ./...`。

## Review Focus

1. **敏感信息**：连接串 `user:pass@tcp(...)` 与 `password=...` 不得出现在日志里。（Task 1、Task 2）
2. **未初始化/关闭后**：`LogInfo` 等在任何阶段被调用都不得 panic（含 `Close` 之后）。（Task 1）
3. **长跑膨胀**：一天一文件 + 单文件 5MB 轮转；时区跨天要换文件。（Task 1）
4. **panic 兜底**：视图构建 panic 必须被 recover、记堆栈、应用继续跑（顶栏有错误提示）。（Task 2）
5. **日志路径可达**：设置窗口能显示真实路径并调起文件管理器；headless 下不崩。（Task 3）

**Files:**

**Interfaces:**

  ```go
  type LogLevel int // LogDebug/LogInfo/LogWarn/LogError
  func DefaultLogDir() string                       // <configDir>/db-g/logs
  type Logger struct{ /* dir, now, level, maxSize, alsoStderr, … */ }
  func NewLogger(dir string) (*Logger, error)       // 打开/创建当天文件
  func (l *Logger) SetLevel(level LogLevel)
  func (l *Logger) Log(level LogLevel, tag, msg string, kv ...any) // kv 交替 key,value
  func (l *Logger) Close() error
  func (l *Logger) Path() string                    // 当前日志文件路径
  func InitLogs(dir string) error                   // 设置包级默认日志（供 ui 使用）
  func CloseLogs()
  func LogInfo(tag, msg string, kv ...any)          // 未初始化时 no-op
  func LogWarn(tag, msg string, kv ...any)
  func LogError(tag, msg string, kv ...any)
  func RedactDSN(s string) string                   // 把 password=…/user:pass@ 脱敏
  ```
  日志行：`{"ts":"2026-11-05T10:00:00.123+08:00","level":"info","tag":"exec","msg":"ok","kv":{"dur_ms":3,"rows":500}}`

```go
func TestLoggerWritesJSONLine(t *testing.T) {
	dir := t.TempDir()
	l, err := NewLogger(dir)
	if err != nil {
		t.Fatal(err)
	}
	defer l.Close()
	l.Log(LogInfo, "exec", "ok", "dur_ms", 3, "rows", 500)

	if err != nil {
		t.Fatal(err)

	}
}
```

- 轮转命名：`app-YYYYMMDD.log`；超限时 rename 到 `app-YYYYMMDD.1.log`（覆盖旧的 `.1`）后重开。

```go
func initTestLogs(t *testing.T) string {
	t.Helper()
	dir := t.TempDir()
	if err := app.InitLogs(dir); err != nil {
		t.Fatal(err)
	}
	t.Cleanup(app.CloseLogs)
	return dir
}

func readLogs(t *testing.T, dir string) string {
	t.Helper()
	entries, _ := os.ReadDir(dir)
	var b strings.Builder
	for _, e := range entries {
		data, _ := os.ReadFile(filepath.Join(dir, e.Name()))
		b.Write(data)
	}
	return b.String()
}

func TestOpenConnLogsWithoutPassword(t *testing.T) {
	dir := initTestLogs(t)
	a := newConsoleRoot(t)
	prof := app.ConnProfile{Name: "本地", Kind: "sqlite", Path: seedConnFile(t)}
```
