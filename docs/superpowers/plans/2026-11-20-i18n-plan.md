# 国际化（中文 / 英文）实施计划

设计：`docs/superpowers/specs/2026-11-20-i18n-design.md`

已拍板：默认跟随系统；v1 做到 P3；AI 回答跟随界面语言；**驱动层报错原样展示，不翻译、不二次包装**。

> 关键预研结论（headless 测试）：`mygo.App.Locale()` / `App.ChosenLocale()` 在 `ui` 包的 headless
> 测试里会等待主线程而卡死。因此**设置页不得读取这两个 API**，语言选择只读 `root.localePref`；
> 测试进程用 `MYGO_LOCALE` + 已注册 catalog 解析语言（`i18n.Locale()` 在该路径不阻塞）。

## 阶段 P0：脚手架与语言开关

### 1. catalog 与生成代码

- `mygo.json` 增加：

  ```json
  "i18n": { "dir": "locales", "source": "en" }
  ```

- 新建 `locales/en.json`（源语言，完整版最终在这里）与 `locales/zh-Hans.json`。
  P0 先放骨架：设置导航 11 项、语言分区、通用按钮（保存/取消/删除/关闭）。
- 运行 `go tool mygo generate`（或 `go tool mygo dev` 启动时自动生成）提交 `locales/catalog_gen.go`。
- `locales/catalog_test.go`：en/zh-Hans key 集合一致、占位符名一致、英文目录无 CJK。

### 2. 语言偏好落盘

- `app/locale.go`：

  ```go
  type LocalizationPrefs struct {
      Locale string `json:"locale"` // ""=跟随系统，否则 zh-Hans / en
  }
  func DefaultLocalePrefs() LocalizationPrefs
  func NormalizeLocalePrefs(p LocalizationPrefs) LocalizationPrefs
  func DefaultLocalePrefsPath() string
  func LoadLocalePrefs(path string) (LocalizationPrefs, string)
  func SaveLocalePrefs(path string, p LocalizationPrefs) error
  ```

  归一化：空串保留；`zh-Hans`/`zh` 归一为 `zh-Hans`；`en`/`en-*` 归一为 `en`；其他未知值回退 `""`
  并返回警告（与 `LoadThemePrefs` 同一套路，0600、临时文件 + rename）。
- 测试：默认值、归一化、往返、损坏文件回退。

### 3. 启动接线

- `main.go`：在 `mygo.App.Run()` 前加载 `app.LoadLocalePrefs(app.DefaultLocalePrefsPath())`，
  调用 `mygo.App.SetLocale(prefs.Locale)`（`""` 即跟随系统）。
- 确保 `locales` 包被 import（`ui` 使用即可）；mygo 生成代码会注册 catalog 并自动链接
  `github.com/egoist/mygo/locales/zh-Hans`。
- 更新弹窗无需改代码，随 `App.Locale()` 生效。

### 4. 设置页「语言」分区

- `ui/settings.go` 的 `settingsSections()` 加 `{locales.SettingsLanguage(), a.languageSection}`（放在外观后）。
- `languageSection`：三段 `Segmented`（系统默认 / 简体中文 / English），选中项来自 `a.localePref`；
  切换时：
  1. `a.localePref = tag`
  2. `app.SaveLocalePrefs(a.localePrefsPath, prefs)`
  3. `if a.win != nil { mygo.App.SetLocale(tag) }`（headless 测试不碰 mygo）
- `ui/root.go`：新增 `localePref string`、`localePrefsPath string`，在 `NewRoot`/测试构造路径里加载。
- 现有分区标签也改为 `locales.SettingsAppearance()` 等。

### 5. 测试固化中文

- `ui/i18n_test.go` 加 `TestMain`：未设置 `MYGO_LOCALE` 时设为 `zh-Hans`，保证现有中文断言不变。
- 新增 headless 用例：点击「语言」分区 → 选择 English → 断言 `locale.json` 写入 `en` 且
  `a.localePref == "en"`；不调用会阻塞的 `App.Locale()`。
- 英文目录冒烟：`locales.In("en").SettingsLanguage() == "Language"`。
- 完整校验：

  ```bash
  CGO_ENABLED=0 go build ./... && CGO_ENABLED=0 go vet ./... && CGO_ENABLED=0 go test -p 1 ./...
  go tool mygo vet . && gofmt -l .
  ```

### P0 验收

- 中文系统启动：更新弹窗中文；英文系统启动：更新弹窗英文。
- 设置切 English：已迁移的文案立即变英文，重启保持；切回中文立即恢复。
- 现有测试全绿。

## 阶段 P1：主窗口骨架

- 迁移 `ui/titlebar.go`、`sidebar.go`、`tabs.go`、`result.go`（进度/工具条/分页/空态/只读原因）、
  `resultfooter.go`、`history.go`、`run.go`、`code.go`、`sessions.go`。
- 包级标签表改为渲染期解析：`keyActions.Label`、`themeSchemeOptions`、`themeAccentOptions`、
  `connKinds`、`objectKinds`、`tagColorSpecs`。
- 设置窗口五个高频分区（外观/语言/字体/结果/控制台）完整迁移。
- 验收：英文模式下，日常「连库 → 写 SQL → 执行 → 看结果 → 翻页」路径无中文。

## 阶段 P2：对话框与剩余设置

- 连接弹窗、测试连接、对象树右键/DDL、外部控制台、导入/导出、同步设置与弹窗、AI 面板/设置/调试、
  安装/升级、日志/开发分区、guard 错误条。
- 验收：所有弹窗、右键菜单、Tooltip、空态在英文模式下为英文；固定宽度面板无溢出。

## 阶段 P3：app 层错误与 AI 语言

- 更新 `AGENTS.md`：允许 `app` import `db-g/locales`（生成叶子包，仅文案）；`engine`/`driver`/`sync`
  保持不变。
- 迁移 `app/conn.go`、`consolemgr.go`、`export.go`、`editable.go`、`selfinstall.go`、`themeprefs.go`、
  `syncservice.go` 的用户可见文案；包装底层错误时保留原始错误文本。
- AI：`ui` 把当前语言（从 catalog/i18n 解析，不调用会阻塞的 API）传给 `ai` 请求；提示词要求回答
  使用该语言。`ai` 包不 import mygo。
- 驱动层错误：**不动**（设计已拍板）。
- 验收：英文模式下连接校验、控制台命名/外部文件冲突、导出/导入、同步配置错误均为英文，
  数据库服务端报错保持原文。

## 阶段 P4：规范收尾

- `tools/l10nscan` 或 `make i18n-status`：AST 统计各包剩余中文字面量，输出白名单外清单。
- CI：`ui/` 中文字面量为 0；`locales` key 对齐；`go tool mygo i18n check locales`。
- 文档：`Readme.md` / `README.en.md` 功能清单、`AGENTS.md` 文案规范、roadmap 非目标标记撤销。
- 人工验收：中文/英文系统 + 设置强制切换 + 更新弹窗。

## 风险控制

- 每阶段结束跑完整校验；不跨阶段混提交。
- 任何新增 UI 文案必须同时加 en + zh-Hans 两个 key，禁止硬编码中文。
- 迁移时先跑测试再改文案；测试断言语言固定为 `zh-Hans`。
