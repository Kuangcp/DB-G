# DB-G v1.0.4

新外观、结果区编辑与 Git 同步。仍需一个可执行文件、四类数据源、本地优先。

## 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows x64 | `db-g-setup-1.0.4-amd64.exe` | Windows 10 / 11；每用户安装，支持签名自动更新 |
| Linux x64 | `db-g-1.0.4-linux-amd64.tar.gz` | 含 `install.sh`，解压后安装到用户目录 |
| Linux x64（Debian/Ubuntu） | `db-g_1.0.4_amd64.deb` | 也可直接 `dpkg -i` 安装 |
| 增量更新 | `db-g-1.0.3-to-1.0.4-linux-amd64.delta` | 从 v1.0.3 升级的 Linux 增量包 |

`SHA256SUMS` 与各平台 `update-*.json` 随 Release 资产提供；自动更新使用签名清单校验。
文件大小与校验值以 Release 页面实际资产为准。

## 运行要求

- **Windows 10 / 11 x64**：双击安装包或可执行文件。原生界面，不需要 WebView2、.NET 或 Java。
- **Linux x64（glibc）**：需要 GTK 3。
  Arch `gtk3`、Debian/Ubuntu `libgtk-3-0`、Fedora `gtk3`。
- 仅提供 Windows x64 与 Linux x64；Linux 构建不适用于 Alpine 等 musl 发行版。

## 本版重点

### 界面

- 接入 [Lobe UI](https://github.com/lobehub/lobe-ui) 设计 token，统一浅/深色的背景、容器、
  边框、文字层级与强调色。
- 内置 默认 / 海洋 / 森林 / 暖阳 配色；支持自定义浅色/深色各 5 项中性色。
- 自绘无边框标题栏：整条可拖动、双击最大化，右上角为打开 SQL、历史、AI 助手、设置与
  最小化/最大化/关闭；窗口圆角跟随外观设置（macOS / Windows 11）。
- 主窗口与设置窗口记住大小和位置。

### 结果区

- 查询结果支持刷新重跑（原 Tab 内重新执行）。
- `Ctrl+双击` 单元格进入编辑：短内容在表格内改，长内容打开弹窗。
- 查看/编辑弹窗按内容自适应，右下角可拖拽缩放；查看器可切换自动折行。
- 结果大小预算可配置（默认 8MB）；导出显示进度与已写行数，未完成导出退出前会确认。
- 结果表只渲染单元格前缀，超长字段不再拖慢切换；复制/查看仍取完整内容。

### AI

- AI 改写选中 SQL：`Ctrl+K`，先查看上下文，再以 diff 预览决定是否替换。
- AI 设置自动读取 `/models` 模型列表；提供 `Ctrl+K` 改写与 AI 会话历史。
- 语句执行状态改为行号旁圆点，注释快捷键 `Ctrl+/` 后光标自动下移。

### Git 同步

- 设置窗口「同步」分区配置仓库地址、分支与可选 SSH 私钥。
- 「拉取」/「提交并推送」双向同步连接、文件夹、工作区与内部控制台 SQL。
- 连接信息整条加密，控制台 SQL 明文；提交前扫描疑似明文凭据并要求确认。
- 拉取保留本地独有数据；空仓库首次拉取自动 clone 初始化，提交先合并远端再推送。

### 命令行

- `db-g -o /path/to/aa.sql` 打开 SQL 文件（可重复），已有实例运行时转交并聚焦，不再开新窗口。
- `db-g -version` 打印版本。

## 数据位置

- Linux：`~/.config/db-g/`
- Windows：`%AppData%\db-g\`

包含 `connections.json`（密码已加密）、`consoles/`、`meta/`、`history/<connectionID>.jsonl`、
`logs/`、`theme.json`、`window-state.json`、`keymap.json`；同步密钥在 `sync.key`。

## 已知限制

- 仅 Windows x64 与 Linux x64；Linux 需要 glibc。
- Windows 可执行文件未做代码签名，SmartScreen 可能提示“未知发布者”，选择“仍要运行”即可。
- ClickHouse 为只读数据源；结果编辑仅支持单表 + 主键可识别的查询。
- 外部文件控制台、执行历史、缓存、光标与主题/快捷键/AI 配置不参与 Git 同步。

## 从源码构建

```bash
CGO_ENABLED=0 go1.27 build -trimpath -buildvcs=false -tags mygo_noinspector \
  -ldflags "-s -w -X db-g/app.buildVersion=1.0.4 -X github.com/egoist/mygo.production=1"
```

或直接 `make release`，产物在 `dist/`。
