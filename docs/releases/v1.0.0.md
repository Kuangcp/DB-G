## 运行

- **Windows 10 / 11 x64**：双击 `db-g-v1.0.0-windows-amd64.exe`。原生界面，不需要 WebView2、.NET 或 Java。
- **Linux x64（glibc）**：需要 GTK 3，然后

  ```bash
  chmod +x db-g-v1.0.0-linux-amd64
  ./db-g-v1.0.0-linux-amd64
  ```

  GTK 3 包名：Arch `gtk3`、Debian/Ubuntu `libgtk-3-0`、Fedora `gtk3`。

命令行参数：`db-g -version` 打印版本。

## 本版功能

- **数据源**：SQLite、MySQL、PostgreSQL、ClickHouse（只读）；连接、执行、对象树、列目录/主键、SQL 补全、DDL 查看、导出。
- **编辑器**：SQL 高亮、行号、查找替换、折叠、多光标、撤销，百万行级视口；保守格式化（只改空白与关键字大小写）。
- **执行**：`Ctrl+Enter` 执行光标语句或选区；多语句顺序执行、失败即停，每条语句一个结果 Tab，成功/失败用绿/红状态点标记。
- **结果区**：单元格级选择与复制；右键排序/筛选；JSON 折叠树查看；结果钉住对比（最多 10 个，切控制台各自保留）；`取更多` 分页追加；CSV / JSON / SQL INSERT 导出，支持全量流式导出。
- **写操作**：单表 + 主键的结果可改格、增行、删行；提交前预览参数化 SQL，单事务执行，影响行数不符整体回滚。
- **大库**：对象按页加载（每页 1000，单组上限 5000）+ 24 小时磁盘缓存，连接与展开不阻塞 UI。
- **工作区**：一个数据源多个命名控制台，正文自动落盘并重启恢复；`Ctrl+Tab` 切换最近控制台；标签可 Ctrl 拖动排序。
- **本地优先**：连接密码使用 AES-256-GCM 本机加密（密钥 `secret.key`，0600）；日志自动脱敏 DSN/密码；无账号、无遥测。
- **界面**：跟随系统/浅色/深色，强调色、密度、圆角、字号可调并即时生效；快捷键统一动作表，可在设置里改绑。

## 已知限制

- 仅提供 Windows x64 与 Linux x64 构建；Linux 构建依赖 glibc，不适用于 Alpine 等 musl 发行版。
- Windows 可执行文件未做代码签名，SmartScreen 可能提示“未知发布者”，选择“仍要运行”即可。
- ClickHouse 为只读数据源；结果编辑仅支持单表 + 主键可识别的查询。
- 导出、日志、控制台等文件都落在本地配置目录，不会云同步。

## 数据位置

- Linux：`~/.config/db-g/`
- Windows：`%AppData%\db-g\`

里面有 `connections.json`（密码已加密）、`consoles/`、`meta/`、`history.jsonl`、`logs/`、`theme.json`、`editor.json`、`keymap.json`。

## 从源码构建

```bash
CGO_ENABLED=0 go1.27 build -trimpath -buildvcs=false -tags mygo_noinspector \
  -ldflags "-s -w -X db-g/app.buildVersion=v1.0.0 -X github.com/egoist/mygo.production=1"
```

或直接 `make release`，产物在 `dist/`。
